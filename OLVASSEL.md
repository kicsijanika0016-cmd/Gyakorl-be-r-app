# Eredménytáblázat – Android APK

1. Hozz létre egy GitHub fiókot (ingyenes) és egy új, üres repót.
2. Töltsd fel ide a mappa teljes tartalmát (a rejtett `.github` mappával együtt!).
3. A repo "Actions" fülén az "APK építés" automatikusan lefut (~5 perc).
4. A lefutott munkamenetnél az "Artifacts" alatt töltsd le: Eredmenytablazat-APK (zip), benne van az app-debug.apk.
5. Másold a telefonra, nyisd meg, engedélyezd az "ismeretlen forrásból telepítést".
